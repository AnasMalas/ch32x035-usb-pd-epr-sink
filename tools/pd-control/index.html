PPS regulator and source health

PPS_Status reports source-side voltage, current, temperature, and whether the regulator is in CV or current-limit mode.

PPS regulator Unknown No PPS status received
Source measurement — Source-reported, not a precision power meter
Temperature and input — No general status received

A compliant PPS source sends an Alert when it changes between CV and CL; the firmware then reads general Status automatically. Optional polling helps with sources that do not send that Alert.

Current is requested from the source; usable current is an allowed draw, not a live measurement. Advertised 3.3 V PPS is supported, although that PPS endpoint is deprecated in current USB PD. The EPR AVS compatibility option can use a source-advertised range outside nominal 15-48 V, but never above 50 V and only with firmware configured for it.
