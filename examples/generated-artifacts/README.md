# Generated example artifacts

The two example applications place local build outputs here:

- `ch32x035-usb-pd-epr-sink-reference-<profile>.elf` from the firmware build;
- `usb-pd-control.html` from the browser-client packager; and
- optional maps or captures created during local investigation.

Only this README is tracked. Generated files are ignored because they depend
on the exact toolchain, features, and source revision and may become stale.
Rebuild an artifact before testing it; the flash script prints its timestamp
and SHA-256 before programming.

Tagged, reviewed binaries belong in a GitHub Release rather than in this
working directory.
