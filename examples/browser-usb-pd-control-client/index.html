RDO=0x…
The exact 32-bit USB PD Request Data Object sent over CC. It is an on-wire value, not a console command.
raw=0x…
The source's exact advertised 32-bit PDO before the browser decodes voltage, current, range, and flags.
RAW Serial/WebUSB
Exact host USB CDC bytes in hexadecimal. These are control-transport chunks, not CC packets; browser read boundaries are arbitrary. The latest 1,000 chunks are cached while Raw stream is Off and appear when it is turned On.
Contract refresh confirmed
A repeated PPS Request completed successfully. EPR keepalives are more frequent internal housekeeping and are intentionally shown only when a failure causes recovery.
Hard reset … cause=
Shows whether the source signaled the reset or which sink recovery category initiated it. Load cutoff still happens immediately for every cause.
